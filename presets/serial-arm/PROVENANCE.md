# Provenance

These example robots are copied unchanged from
[`python/examples/serial_arm`](https://github.com/batuhantoker/4dof-robotic-arm/tree/a2043a14164371bd95f44dd9865d8383d2701d26/python/examples/serial_arm)
in **batuhantoker/4dof-robotic-arm** at commit `a2043a1`, where they are read by
`serial-arm-analyze`. They are the robots the studio's tests compare against the Python
implementation (`npm run fixtures`). Keep them byte-identical to that commit; to change a
preset, change it upstream and bump the pinned commit in `scripts/fixtures/upstream.mjs`.
